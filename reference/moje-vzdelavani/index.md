# Moje vzdělávání

Záložka **Moje vzdělávání** je výchozí obrazovkou Portálu. Zobrazuje přehled všech kurzů a aktivit, které máte aktuálně přiřazeny – jak jednotlivé aktivity, tak kurzy sestavené ze sady více částí.

## Přehled obrazovky

Obrázek

Obrázek obrazovky Moje vzdělávání bude doplněn.

## Prvky obrazovky

| Prvek                          | Umístění     | Popis                                                                                                                                                |
| ------------------------------ | ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Předdefinované pohledy** (1) | horní část   | Přepínač mezi kategoriemi kurzů – například Vše, Hotové kurzy nebo další pohledy podle konfigurace Vašeho portálu.                                   |
| **Vyhledávání** (2)            | horní část   | Textové pole pro filtrování kurzů podle názvu.                                                                                                       |
| **Filtry** (3)                 | levá část    | Omezení zobrazeného seznamu podle povinnosti, typu vzdělávání, délky kurzu nebo období konání. Dostupné filtry se mohou lišit dle nastavení portálu. |
| **Řazení** (4)                 | nad seznamem | Výběr pořadí kurzů – například podle doporučeného pořadí, abecedně nebo podle nejbližšího termínu.                                                   |
| **Přepínač zobrazení** (5)     | nad seznamem | Přepnutí mezi zobrazením jako seznam nebo dlaždice.                                                                                                  |
| **Části kurzu** (6)            | u sady       | Rozbalení sady na jednotlivé části. U termínových aktivit se zobrazuje informace o konkrétním datu konání.                                           |

Kategorie a štítky

Kurzy lze členit do kategorií a podkategorií pomocí štítků. Strukturu kategorií i dostupné filtry nastavuje administrátor portálu – obsah se proto může lišit mezi pracovišti.

## Položka v seznamu kurzů

Každá položka v seznamu obsahuje tyto informace:

Obrázek

Obrázek ukázkové položky kurzu bude doplněn.

| Prvek                    | Popis                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------ |
| **Název** (1)            | Název kurzu nebo aktivity.                                                                       |
| **Typ** (2)              | Druh obsahu – například e-learning, školení nebo sada.                                           |
| **Štítek** (3)           | Volitelný popis nebo kategorie přiřazená kurzu.                                                  |
| **Termín dokončení** (4) | Datum, do kdy je kurz nebo aktivita požadována.                                                  |
| **Aktuální stav** (5)    | Stav plnění – například splněno nebo nesplněno.                                                  |
| **Tlačítko Spustit** (6) | Tlačítko pro zahájení kurzu nebo aktivity. Zobrazuje se tehdy, kdy je kurz dostupný ke spuštění. |
